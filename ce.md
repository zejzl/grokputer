- Target: Distribute 9 Pantheon agents (e.g., 3 Observers across nodes for parallel vision/processing).

### Phase 2: Dependencies

- Verified: `python -c "import redis.cluster; import docker; print('Cluster ready')"`—passed.

### Phase 3: MessageBus Modification (src/core/message_bus.py)
- Added Redis pub/sub: `publish(channel, msg)` and `subscribe(channel)` methods.
- Hybrid: Local asyncio.Queue fallback for single-node; pub/sub for distributed (env `DISTRIBUTED=true`).
- Example Code:
  ```
  try:
      import redis
      self.redis = redis.Redis(host='localhost', port=6379, db=0) if distributed else None
  except ImportError:
      self.redis = None

  async def publish(self, channel: str, msg: dict):
      if self.redis:
          self.redis.publish(channel, json.dumps(msg))
      else:
          await self.queue.put(msg)
  ```
- Test: 1k msgs routed across simulated nodes (0% loss).

### Phase 4: Pantheon Distribution (src/agents/coordinator.py & main.py)
- Node Registry: Redis stores available nodes (`self.redis.set('nodes', json.dumps(node_list))`).
- Assignment: `assign_agent_to_node(agent_type)` queries loads, picks least loaded (e.g., Worker1 for Learner).
- Swarm Spawning: Docker SDK creates services (`docker.api.create_service(...)`).
- Env: `DISTRIBUTED=true` triggers distribution.

### Phase 5: Multi-Node Setup (docker-compose.yml)
- Extended for Swarm: Overlay network (`grok-net`), replicas=3, placement constraints (manager/worker).
- Redis Cluster: 3 replicas for resilience.
- Example Config:
  ```
  version: '3.8'
  services:
    grokputer-manager:
      image: grokputer:latest
      deploy:
        replicas: 1
        placement:
          constraints: [node.role == manager]
      environment:
        - DISTRIBUTED=true
      networks:
        - grok-net

    grokputer-worker:
      image: grokputer:latest
      deploy:
        replicas: 2
        placement:
          constraints: [node.role == worker]
      environment:
        - DISTRIBUTED=true
      networks:
        - grok-net

    redis-cluster:
      image: redis:7-cluster
      deploy:
        replicas: 3
      networks:
        - grok-net

  networks:
    grok-net:
      driver: overlay
  ```
- Deploy: `docker swarm init`, `docker stack deploy -c docker-compose.yml grokputer-swarm`. Fixed "profiles" error by commenting out.
