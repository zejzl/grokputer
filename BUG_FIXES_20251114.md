## Bug 1: ActorAgent MessageBus Registration Failure

### Issue
**Error**: "Unknown agent: actor" causing permanent failure after 3 restart attempts
**Severity**: CRITICAL - Prevents entire Pantheon mode from functioning
**Location**: `src/agents/actor_agent.py` lines 41-51

### Root Cause
The `is_healthy()` method had unreachable code due to premature `return True` statement:

```python
def is_healthy(self) -> bool:
    return True                           # EARLY RETURN - code below never executes!

    # Register with message bus             # UNREACHABLE CODE
    self.message_bus.register_agent(self.agent_id)

    if self.deadlock_detector:             # UNREACHABLE CODE
        self.deadlock_detector.register_agent(self.agent_id)

    self.logger.info(f"[ACTOR] {self.agent_id} initialized")  # UNREACHABLE CODE
```

This caused the actor agent to never register with the MessageBus, leading to "Unknown agent: actor" errors when other agents tried to send messages to it.

### Fix Applied
Moved the registration logic before the return statement and added a safety check:

```python
def is_healthy(self) -> bool:
    # Register with message bus if not already registered
    if self.message_bus and self.agent_id not in self.message_bus.queues:
        self.message_bus.register_agent(self.agent_id)

    if self.deadlock_detector:
        self.deadlock_detector.register_agent(self.agent_id)

    self.logger.info(f"[ACTOR] {self.agent_id} initialized")
    return True                            # NOW at the end - all code executes
```

### Impact
- Actor agent now properly registers with MessageBus on initialization
- Eliminates "Unknown agent: actor" errors
- Prevents permanent failure cascades in Pantheon mode
- Fixes deadlock detection integration

## Bug 2: Nested Event Loop Error in Single-Agent Mode

### Issue
**Error**: "asyncio.run() cannot be called from a running event loop"
**Severity**: HIGH - Crashes single-agent mode completely
**Location**: `main.py` line 1083

### Root Cause
The `_run_single_agent_mode()` function is already async and called with `asyncio.run()` from the main CLI handler. Inside this async function, the code incorrectly called `asyncio.run()` again, creating a nested event loop:

```python
async def _run_single_agent_mode(...):
    try:
        grokputer = Grokputer(debug=debug, provider=provider, model=model)
        if not skip_boot:
            grokputer.boot()
        await asyncio.run(grokputer.run_task(...))  # NESTED asyncio.run() - ILLEGAL!
    except Exception as e:
        print(f"Fatal error in single agent mode: {e}")
        raise
```

Call chain:
1. `main()` (sync) calls `asyncio.run(_run_single_agent_mode(...))` at line 259
2. `_run_single_agent_mode()` (async) incorrectly calls `asyncio.run()` again
3. Python raises RuntimeError because event loop is already running

### Fix Applied
Removed the nested `asyncio.run()` wrapper since we're already in an async context:

```python
async def _run_single_agent_mode(...):
    try:
        grokputer = Grokputer(debug=debug, provider=provider, model=model)
        if not skip_boot:
            grokputer.boot()
        # Already in async context, don't use asyncio.run()
        await grokputer.run_task(task=task, max_iterations=max_iterations)
    except Exception as e:
        print(f"Fatal error in single agent mode: {e}")
        raise
```

### Impact
- Single-agent mode now works correctly
- Proper async/await pattern maintained throughout call stack
- No more nested event loop errors

## Bug 3: Missing 'os' Import in DocumentationAgent

### Issue
**Error**: "Failed to initialize AI client for DocumentationAgent: name 'os' is not defined"
**Severity**: MEDIUM - Prevents DocumentationAgent from initializing AI client
**Location**: `src/agents/documentation_agent.py` line 58

### Root Cause
The `_init_ai_client()` method uses `os.getenv()` without importing the `os` module:

```python
def _init_ai_client(self):
    """Initialize the AI client for documentation generation."""
    try:
        api_key = self.config.get("GROK_API_KEY") or os.getenv("GROK_API_KEY")  # os not imported!
        model = self.config.get("GROK_MODEL", "grok-4-fast-reasoning")
        if api_key:
            self.ai_client = ModelClientFactory.create_client("grok", api_key, model)
        else:
            logger.warning("No GROK_API_KEY found for DocumentationAgent")
            self.ai_client = None
    except Exception as e:
        logger.warning(f"Failed to initialize AI client for DocumentationAgent: {e}")
        self.ai_client = None
```

### Fix Applied
Added `import os` to the module imports:

```python
import ast
import asyncio
import importlib.util
import inspect
import logging
import os                    # ADDED
from pathlib import Path
from typing import Any, Dict, List, Optional
```

### Impact
- DocumentationAgent can now properly initialize AI client
- Environment variable fallback works correctly
- Agent remains functional even if initialization fails (graceful degradation)
