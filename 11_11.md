### 3. src/agents/executor_agent.py - Workflow Orchestration Agent
A new Phase 2 agent implementing complex multi-step workflow orchestration.

**Core Capabilities:**
- **Workflow Management**
  - Stateful execution tracking (PENDING → IN_PROGRESS → COMPLETED/FAILED/PAUSED)
  - Multi-step sequences (e.g., observe-analyze-validate-act loops)
  - Workflow queuing and async processing
  - Context preservation across steps

- **Execution Features**
  - Parallel step execution with dependency resolution
  - Topological sorting for optimal parallel grouping
  - Conditional step execution (Memory/context-based conditions)
  - Timeout handling (30s per step default, configurable)
  - Recovery/retry logic (3 attempts by default)

- **Integration**
  - MessageBus for agent delegation
  - Memory Manager for workflow state persistence
  - Session Logger for observability
  - Deadlock Detector integration

- **Configuration**
  - `max_steps`: 20 (default)
  - `timeout_per_step`: 30 seconds
  - `recovery_retries`: 3
  - `parallel_threshold`: 0.5 (fraction of parallelizable steps)
  - `continue_on_fail`: Optional flag for fault tolerance

**Example Workflow Structure:**
```python
{
    "workflow_id": "test_workflow",
    "steps": [
        {"step_id": "1", "type": "observe", "target": "observer",
         "description": "Capture screen", "deps": []},
        {"step_id": "2", "type": "analyze", "target": "analyzer",
         "description": "OCR text", "deps": ["1"]},
        {"step_id": "3", "type": "act", "target": "actor",
         "description": "Execute action", "deps": ["2"]}
    ],
    "context": {"example": "data"}
}
```

**Message Channels:**
- Listens on: `{agent_id}.execute`
- Sends to: `coordinator` (workflow_complete/workflow_failed)
- Step-specific: `{target}.{step_type}` for delegation
- Result channel: `{workflow_id}.{step_id}.result`
